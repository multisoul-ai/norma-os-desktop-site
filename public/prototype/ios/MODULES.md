# Norma iOS 伴侣 · 模块设计

对照：Cursor Mobile 截图 + grilling（Q9=C、票 02–04）。本文件是原型信息架构，不是生产 SPEC。

## 一句话

手机只做 **注意力闸门 + 对 Norma 的一句指挥**；长会话与舰队监视都是二级，默认不进。

## 页面地图

```
首页（闸门） ──zoom──► Agent 上下文（临时）
   │                      │
   ├──► 全部 Agent（舰队列表）
   ├──► 锁屏 Live Activity（系统层示意）
   └──► 指挥条发送 → 短澄清内联 / 复杂进「需要你」
```

## 模块清单

| 模块 | 职责 | 出现位置 | 不做 |
|------|------|----------|------|
| **需要你** | 打断级决策队列（提问 / 权限 / 失败） | 首页主舞台 | 不做聊天时间线 |
| **决策卡** | 一眼：徽标 + 标题 + 来源 + 一行方案 + 批处理 | 需要你列表 | 不做长证据墙 |
| **摘要** | 完成项只读回顾 | 首页次区 / Hub 磁贴 | 不做再打断 |
| **指挥条** | 对 Norma 短指令；可带「继续：…」resume | 底栏（或 Stacked 顶栏） | 默认不胀成全屏会话 |
| **短澄清** | Norma 二元选择，内联在首页 | 指挥条上方卡片 | 复杂澄清进需要你 |
| **全部 Agent** | Working / Idle 分组列表 | 二级页 | 不是首页主舞台 |
| **看上下文** | 卡住时临时 zoom 进会话 | 从决策卡进入 | 不是默认路径 |
| **锁屏 Live Activity** | 极简：标题 + 短下一步；权限/失败带方案 | 锁屏示意 | 不做心跳刷屏 |

## 三变体只改「编排轴」

共享同一套模块与视觉 token；差异只在首页怎么排：

1. **Quiet** — Cursor 式：大标题 + 干净列表 + **底栏**指挥条（默认推荐方向）
2. **Stacked** — 指挥条 **置顶** + 需要你 / 摘要双区纵叠
3. **Hub** — 「今日」2×2 磁贴分流，再进列表（学 Cursor Inbox 格，但词表用「需要你/摘要」，不用 Inbox）

## 视觉原则（本轮重做要对齐）

- 白底 + 大留白；分隔靠 hairline / 留白，少描边盒子
- 列表行：左图标色点、标题、一行灰 meta；动作克制
- 指挥条：浮层 pill（+ / 输入 / 语音），对标 Cursor Composer
- 圆角圆形图标按钮；彩色只给徽标与功能图标
- 禁止半透明「卡住」的入场动画把内容留在 opacity:0

## 交互主路径（可点）

1. 扫「需要你」→ 处理 / 批准 / 稍后  
2. 指挥条说一句 → 短澄清或进队  
3. 打开摘要看完成  
4. 「看上下文」zoom → 返回  
5. 清空队列 → 空状态「暂时没有需要你的事」  
6. 锁屏示意 / 全部 Agent 二级
