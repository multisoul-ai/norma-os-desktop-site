# Norma OS

Norma OS is a macOS product for directing multiple coding agents inside one persistent spatial workspace. This context keeps the public product language consistent across the website, product copy, and future specifications.

## Language

**Command Center**:
The single Norma OS workspace from which a user directs multiple Coding Agents and observes their ongoing work. This is the product's primary public positioning.
_Avoid_: AI desktop, agent dashboard, window manager

**Norma AI**:
The named coordination interface through which the user delegates, redirects, and monitors work across Coding Agents. Norma AI coordinates the agents rather than replacing them.
_Avoid_: AI companion, chatbot, coding agent

**Coding Agent**:
An independently running software-development agent that Norma OS can coordinate, such as Codex or Claude Code.
_Avoid_: bot, assistant, Live Node

**Live Node**:
A persistent runtime surface in the Norma OS workspace, including Agent, Terminal, Browser, and Preview. A Live Node remains active when the user's attention moves elsewhere.
_Avoid_: card, widget, window

**Liquid Glass**:
Norma OS's color-neutral visual material language, expressed through translucency, refraction, highlights, and layered depth. Purple is not part of its defining identity.
_Avoid_: purple glass, neon gradient, blur-only decoration
